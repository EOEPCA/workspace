# Tutorials

Start with the [quickstart](../getting-started/quickstart.md) to create a team workspace, share buckets, and run services.

The notebooks cover individual tasks:

- [Workspace Management](../workspace-management.ipynb): create a workspace, check access, open its dashboard and Datalab, upload images, and share them.
- [Resource registration](../getting-started/cng-resource-registration.ipynb): package STAC metadata in an OCI registry and start a STAC API.
- [Vienna imagery](../getting-started/vienna-stac-s3.ipynb): publish satellite images and read them through STAC and S3.
